- Issue：https://github.com/NVIDIA/TensorRT/issues/4581
- Baseline：c93b7d48；交付目標 yenhao-huang/TensorRT fork。
- 已讀完整 body（要求更新 deprecated flags 並展示等效精度選擇）、comments（無）、timeline（label/subscription）、PR／commit4581搜尋（無）。大部分 samples 已遷移，剩餘有效 BuilderFlag.FP16 呼叫在 IntroNotebooks helper；同目錄 notebook2 仍使用 --fp16。

## 實作前驗收條件

1. 移除 IntroNotebooks 使用已移除 FP16 builder flag 的路徑，展示在 ONNX 模型中指定精度、建立強型別 engine。
2. FP32 與 FP16 路徑均可 build／GPU inference，buffer dtype 和 shape 必須符合 engine，而非僅更改 NumPy dtype。
3. notebook 提供同一正規化輸入上的框架／TensorRT 數值比較，明確區分 logits 與機率，不以單張 top-k 代替數值驗證。
4. 可用 pretrained ResNet50 驗證精度遷移；另以小模型回歸測試 helper 的 parse／build 行為。沒有執行的 notebook cell 或版本不得宣稱通過。

## Baseline 重現

TensorRT11.2.1.2、Python3.12.13，/data/tenserrt/venv-trt11。建立 FP32 Identity ONNX (1,3)，呼叫現有 convert_onnx_to_engine(path) 的預設參數，尚未 parse 即失敗：


log：/data/tenserrt/logs/4581/baseline.log；模型：/data/tenserrt/investigations/4581/identity.onnx。

Notebook2 初始 export 為 FP32，之後依 USE_FP16 用 --fp16 和 IOFormats 建立 engine；其說明誤稱 runtime batch dtype 會決定全網精度。preprocess_image 還硬編碼 np.float16，故 USE_FP16=False 也不一致。這些問題需一起修正才能提供可執行的精度教學。

## 實作

- helper 保留 fp16_mode 參數及預設 True：改以 onnxconverter-common 明確轉換 FP32 ONNX，keep_io_types=True 保留 I/O。False 則保留原圖精度，適用既有 FP32／FP16／mixed-precision 模型。使用 strongly typed network，移除 BuilderFlag.FP16；parse／build 失敗會明確報錯，不產生壞 engine 檔。
- 這保留參數介面，但不是舊版 FP16 builder tactic-selection 的相同政策；新圖明確指定運算型別。README 說明精度差異與已轉換模型須傳 False，不重複轉換。
- converter 使用 FP16 最小 subnormal 2^-24、最大 finite 65504 的常數範圍，保留其預設 FP32 op blocklist。小於此範圍的非零常數可能被截斷；實際 ResNet50 轉換有此 warning，沒有隱藏。參考：[官方轉換文件](https://onnxruntime.ai/docs/performance/model-optimizations/float16.html)。
- Notebook2 在 export 前選擇 USE_FP16，用模型與 dummy input 的明確 dtype 匯出；build 時 fp16_mode=False 保留此圖。移除 --fp16／IOFormats 的舊路徑。
- 統一框架／TensorRT 的 ImageNet normalization，修正 FP32 路徑仍硬編碼 FP16 preprocessing、half() 改動原 FP32 baseline 等問題。以 engine metadata 配置 buffers，拒絕錯誤 shape／dtype／非連續陣列，檢查 enqueue。
- 輸出標為 logits，加入同精度 PyTorch 與 FP32 baseline 的逐值比較；Notebook1 也更正 runtime dtype 決定網路精度的錯誤敘述。使用同一 builder logger 建立 runtime，保留其生命週期。
- 為 FP32 對照關閉 TF32。初次 TRT11.2 config.get_flag(TF32)=True；ResNet50 random-input 比較出現45/1000個值超出1e-3容差、違反項最大abs約0.00279224。關閉後使用原容差通過；沒有透過放寬 FP32 容差掩蓋差異。

evaluate_notebook.py：

```python
import json
import sys
from pathlib import Path
import numpy as np
import tensorrt as trt
from cuda.bindings import runtime as cudart
sys.path.insert(0,'/workspace/tenserrt/TensorRT/quickstart/IntroNotebooks')
from onnx_helper import convert_onnx_to_engine
root=Path('/data/tenserrt/investigations/4581')
notebook=json.loads(Path('/workspace/tenserrt/TensorRT/quickstart/IntroNotebooks/2. Using PyTorch through ONNX.ipynb').read_text())
for name in ['fp32','fp16']:
    serialized, build_logger=convert_onnx_to_engine(root/f'notebook-{name}.onnx',fp16_mode=False)
    (root/f'notebook-{name}.engine').write_bytes(bytes(serialized))
    runtime_logger=build_logger
    runtime=trt.Runtime(runtime_logger)
    engine=runtime.deserialize_cuda_engine(serialized)
    context=engine.create_execution_context()
    data=np.load(root/f'notebook-{name}.npz')
    preprocessed_images=data['images']
    exec(''.join(notebook['cells'][47]['source']))
    exec(''.join(notebook['cells'][49]['source']))
    pred=predict(preprocessed_images).copy()
    reference=data['logits']
    atol,rtol=(0.05,0.02) if name=='fp16' else (0.001,0.001)
    np.testing.assert_allclose(pred,reference,atol=atol,rtol=rtol)
    np.testing.assert_array_equal(pred.argmax(axis=1),reference.argmax(axis=1))
    for bad in [preprocessed_images[:1],preprocessed_images.astype(np.float64),preprocessed_images[:,:,:,::-1]]:
        try:
            predict(bad)
        except ValueError:
            pass
        else:
            raise AssertionError('Invalid input accepted')
    print('PASS',name,'shape',pred.shape,'dtype',pred.dtype,'max_abs',np.max(np.abs(pred.astype(np.float32)-reference.astype(np.float32))),flush=True)
    exec(''.join(notebook['cells'][55]['source']))
    del context,engine,runtime,serialized
```
