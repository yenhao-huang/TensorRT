## Reproduce：實際負索引缺陷

在TensorRT10.6.0與10.16.1.11，原始library同樣把data shape(3,3)、axis1、indices `[[0,0],[1,-1],[2,2]]` 的 `-1` 更新到上一列。README原本宣告合法indices為[-s,s-1]，axis也允許[-r,r-1]，因此這不是無效輸入。

- data=`[[10,20,30],[40,50,60],[70,80,90]]`，updates=`[[1,2],[3,4],[5,6]]`。
- 正確：`[[13,20,30],[40,53,64],[70,80,101]]`。
- baseline實測：`[[13,20,34],[40,53,60],[70,80,101]]`，exit1。
- 日誌：`verify-106.log`、`verify-1016.log`，位於 `/data/tenserrt/logs/4701/`。
- 另外負axis被直接用於dims索引，未正規化。第一輪只修negative indices後，axis1的16案例pass而axis-1的16案例fail；修正axis後全通過。
- 額外搜尋 `ScatterElements negative` 的upstream PR/issues無既有處理紀錄。

## Dev：解決方法

- README新增完整可執行Python範例，明確示範init_libnvinfer_plugins、版本2 creator、INT32 axis、CHAR reduction bytes、BUILD phase、add_plugin_v3、三個execution inputs，以及serialization。INT64 indices與plugin library版本要求均有說明。
- kernel將負index加上axis dimension size，再計算address；共用dispatch入口將負axis加rank，並檢查axis範圍，再存取dims。
- README使用非負數值示範以相容原始10.6 release；另說明舊release的負索引限制與重建此source library的需要。本PR不會改變使用者已安裝的舊wheel。
- `plugin/scatterElementsPlugin/tests/test_scatter_elements.py` 測試真實plugin、engine build、serialize/deserialize、GPU inference與NumPy ufunc.at reference。
- Diff review：正常索引不變；負索引只加一次dimension size；負axis在任何dims存取之前正規化；無改變reduction數學或serialization ABI。無效out-of-bounds indices的處理不屬這次修復。

## 解決後 Demo

以下script直接抽取README的Python code fence執行，建立engine後推論三組inputs。存成 `/data/tenserrt/investigations/4701/verify.py`：

```python
import re
import os
import ctypes
import sys
from pathlib import Path
import numpy as np

repo=Path(sys.argv[1]).resolve()
sys.path.insert(0,str(repo/'samples/python'))
import common_runtime as common
text=(repo/'plugin/scatterElementsPlugin/README.md').read_text()
match=re.search(r'```python\n(.*?)```',text,re.S)
if match is None:
    raise RuntimeError('README has no executable Python usage example')
if os.environ.get('SCATTER_PLUGIN_LIBRARY'):
    library=ctypes.CDLL(os.environ['SCATTER_PLUGIN_LIBRARY'])
    library.initLibNvInferPlugins.argtypes=[ctypes.c_void_p,ctypes.c_char_p]
    library.initLibNvInferPlugins.restype=ctypes.c_bool
    assert library.initLibNvInferPlugins(None,b'')
ns={}
exec(compile(match.group(1),'README.md','exec'),ns)
trt=ns['trt']
print('TensorRT',trt.__version__)
runtime=trt.Runtime(ns['logger'])
engine=runtime.deserialize_cuda_engine(ns['plan'])
assert engine is not None
context=engine.create_execution_context()
inputs,outputs,bindings=common.allocate_buffers(engine)
stream=common.CudaStreamContext()
names=[engine.get_tensor_name(i) for i in range(engine.num_io_tensors) if engine.get_tensor_mode(engine.get_tensor_name(i)) == trt.TensorIOMode.INPUT]
try:
    for idx in [ [[0,0],[1,-1],[2,2]], [[0,1],[2,0],[1,2]], [[-1,-1],[-3,-2],[-2,-2]] ]:
        data=np.arange(1,10,dtype=np.float32).reshape(3,3)*10
        updates=np.arange(1,7,dtype=np.float32).reshape(3,2)
        indices=np.array(idx,dtype=np.int64)
        if '--nonnegative' in sys.argv:
            indices=indices % 3
        expected=data.copy()
        np.add.at(expected,(np.arange(3)[:,None],indices),updates)
        feeds={'data':data,'indices':indices,'updates':updates}
        for name,mem in zip(names,inputs):
            mem.host=feeds[name].ravel()
        actual=common.do_inference(context,engine,bindings,inputs,outputs,stream)[0].reshape(3,3)
        np.testing.assert_array_equal(actual,expected)
        print('indices',indices.tolist(),'output',actual.tolist(),'PASS')
finally:
    common.free_buffers(inputs,outputs)
    stream.free()

```
