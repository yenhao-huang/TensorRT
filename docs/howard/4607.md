## Dev：完整處理兩個根因

1. **沿用既有修正**：原作者Lingavasan的[PR4779](https://github.com/NVIDIA/TensorRT/pull/4779)，原commit `564ca4001f1a88186ce0be54b15a74a5870cbc2d`，以 `git cherry-pick -x` 保留作者／Signed-off-by與來源，在本fork commit `a1ada48b`。不同iteration使用不同OrderedDict，不再互相覆蓋。這部分沒有重寫或宣稱為本次原創。
2. **本次新增**：在input reduction開始前，先設定loader metadata、最多讀取兩筆資料。超過一筆即critical error，提供single-sample／`--no-reduce-inputs`選項；empty loader也明確報錯。錯誤不被broad exception handler吞掉。
3. 只保留的一筆資料透過`fallback_inference(..., data_loader=...)`傳給ORT fallback，不重新建立或重讀一次性generator。新參數為optional，其他呼叫保留原行為。
4. `--no-reduce-inputs`不套用single-sample guard，保留原inputs並減少outputs；原issue明確接受此方案。教程與CLI help都說明限制，並提醒自訂loader／JSON不會被`--iterations 1`截斷。

Diff review：guard在checker和產物建立前執行；islice只讀2筆，不依賴len()、不materialize整個generator；metadata先於讀取設置；一次性iterator保存給fallback；其他shape inference API不改預設行為。

## 解決後 Demo

重現資料由以下程式建立，存成 `/data/tenserrt/investigations/4607/generate.py`：

```python
from pathlib import Path
import onnx
from onnx import helper, TensorProto
p=Path('/data/tenserrt/investigations/4607')
g=helper.make_graph([helper.make_node('Add',['x','y'],['sum']),helper.make_node('Identity',['sum'],['out'])], 'reduce', [helper.make_tensor_value_info(n,TensorProto.FLOAT,[1]) for n in ['x','y']], [helper.make_tensor_value_info('out',TensorProto.FLOAT,[1])])
m=helper.make_model(g,opset_imports=[helper.make_opsetid('',13)],ir_version=9)
onnx.save(m,p/'model.onnx')
(p/'loader.py').write_text('import numpy as np\ndef load_data():\n    for i in range(2):\n        yield {n: np.array([i+1], dtype=np.float32) for n in ["x","y"]}\n')

```

```bash
/data/tenserrt/venv/bin/python /data/tenserrt/investigations/4607/generate.py
cd /data/tenserrt/investigations/4607
/data/tenserrt/venv/bin/polygraphy debug reduce model.onnx \
 --data-loader-script loader.py -o fixed-reduced.onnx --check false
# 預期exit1：多筆資料不得input reduction；不呼叫checker、不輸出模型。
/data/tenserrt/venv/bin/polygraphy debug reduce model.onnx \
 --data-loader-script loader.py --no-reduce-inputs \
 -o fixed-output-only.onnx --check false
# 預期exit0：保留inputs，依checker進行output reduction。
```

實測完全符合上述exit code。第一個命令訊息：`Input reduction only supports a single input iteration. Provide one sample, or use --no-reduce-inputs to reduce outputs with multiple samples.`；第二個命令保存`fixed-output-only.onnx`。日誌 `fixed.log`、`demo-output-only.log`。
