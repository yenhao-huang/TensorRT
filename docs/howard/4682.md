## Dev：根因與修正

TensorRT將同名dimension視為相等，ONNX parser也會繼承ONNX的dim_param。因此原export dictionary把ASR的T、F0/N的2T、最終audio的另一個長度全部叫seq_len，產生錯誤的等式。

- 正確的input命名：ASR=`asr_len`，F0/N共享`prosody_len`，所有batch維度仍共享`batch`。
- 原完整decoder AUDIO_OUT應使用`audio_len`，因generator會upsample；此範例的FEATURES是早期Concat結果，長度確實等於ASR，故維持`asr_len`。
- 原optimization profile可保持28/100/1106與56/200/2212。runtime仍需傳入一致配對；更名不等於把P=2T關係編入profile。
- 不修改模型operators、weights或TensorRT核心；修正的是使用者export annotation。README提供可直接替換原dynamic_axes的完整dictionary。
- `quickstart/dynamic_shapes/sample.py` 由實際PyTorch Conv1d(k3,s2,p1)建立frontend並匯出ONNX、build、serialize/deserialize、GPU執行，使用獨立PyTorch CPU結果驗證。
- sample明確採用dynamo=False，以測原issue的dynamic_axes匯出路徑；README連結modern exporter dynamic_shapes文件，未冒稱兩種API等價。
- Diff review：範例使用強型別FP32、關閉TF32以隔離dtype影響、非預設CUDA stream且同步後讀回、檢查parse/build/shape/binding/enqueue結果、釋放buffers。

依據：[NVIDIA named dimensions](https://docs.nvidia.com/deeplearning/tensorrt/latest/inference-library/dynamic-shapes-basics.html)、[PyTorch ONNX export](https://docs.pytorch.org/docs/stable/onnx_export.html)。

## Regression：只改dimension names的證據

`/data/tenserrt/investigations/4682/compare_models.py`內容如下：

```python
from pathlib import Path
import onnx
root = Path('/data/tenserrt/investigations/4682')
for bad, fixed in [('bad-torch', 'fixed-torch'), ('bad-11', 'fixed-11')]:
    a = onnx.load(root / bad / 'frontend.onnx')
    b = onnx.load(root / fixed / 'frontend.onnx')
    assert [n.SerializeToString() for n in a.graph.node] == [n.SerializeToString() for n in b.graph.node]
    assert [n.SerializeToString() for n in a.graph.initializer] == [n.SerializeToString() for n in b.graph.initializer]
    for value in a.graph.input:
        if value.name in ['F0_PRED', 'N_PRED']:
            value.type.tensor_type.shape.dim[1].dim_param = 'prosody_len'
    assert a.SerializeToString() == b.SerializeToString()
    print(bad, fixed, 'PASS: only two input dimension names differ')

```

```bash
/data/tenserrt/venv/bin/python /data/tenserrt/investigations/4682/compare_models.py
```

exit0，兩組bad/fixed配對皆PASS。先比較每個operator及initializer序列化內容完全相同，再只修兩個dim_param，整份ModelProto序列化內容即完全相等。不是藉由改變圖計算或權重繞過錯誤。log `compare-models.log`。

所有日誌皆在 `/data/tenserrt/logs/4682/`。`git diff --check`與sample Black格式檢查通過。
