## reproduce

Issue OPEN，2025-11-14 建立，comments/timeline 為空，PR 與 commit 搜尋 #4643 無結果。`python/docstrings/infer/pyCoreDoc.h` 的 set_device_memory 使用 enqueue_v3，並寫成該呼叫返回後記憶體即可釋放；Python bindings 沒有此方法。`python/src/infer/pyCore.cpp` 實際將 execute_async_v3 綁定至對應 C++ enqueueV3。

## dev

將不存在的 enqueue_v3 改為 execute_async_v3，並將使用期限改為「network execution is complete」。補上 execute_v2 同步返回規則，與同檔 device_memory property 及 `include/NvInferRuntime.h` 的 setDeviceMemoryV2 說明一致。未修改 runtime 或 binding 行為。

## regression test／Demo

環境：Python 3.12.13、TensorRT 10.16.1.11、Sphinx 9.1.0。此為文件修正，不新增 runtime unit test。從實際修改的 C++ raw string 擷取 reST，在小型 Sphinx 文件中建立實際 Python API 存在的方法目標，啟用 nitpicky 與 warnings-as-errors 檢查。

| 驗證 | Baseline | Fixed |
| --- | --- | --- |
| referenced method 的 hasattr(IExecutionContext, name) | enqueue_v3=False | execute_async_v3=True、execute_v2=True |
| Sphinx -n -W --keep-going | exit 1，2個 unresolved enqueue_v3 warnings | exit 0，零 warnings |
| 產生 HTML 的方法連結 | 無有效 enqueue_v3 target | execute_async_v3、execute_v2 均指向同頁已宣告方法 |
| 語意對照 C++ API 與既有 Python property | 錯誤地寫成 enqueue 返回即結束 | 非同步直到網路執行完成，同步直到函式返回 |

Baseline 使用相同命令，擷取未修改 raw string 至 baseline-src，輸出 baseline-html。全部 log 與 HTML 在 `/data/tenserrt/logs/4643/`。這是擷取實際 docstring 的 focused render，沒有重建整個 TensorRT wheel 或官方網站；已安裝 wheel 的 docstring 不會被 source edit 更新。

重現 rendering helper：

```python
import pathlib, re, sys
import tensorrt as trt
source=pathlib.Path(sys.argv[1])
root=pathlib.Path(sys.argv[2]); root.mkdir(parents=True,exist_ok=True)
text=source.read_text()
doc=re.search(r'constexpr char const\* set_device_memory = R"trtdoc\((.*?)\)trtdoc";',text,re.S).group(1)
refs=re.findall(r':func:`([^`]+)`',doc)
print('TensorRT',trt.__version__)
print('Referenced methods:',{r:hasattr(trt.IExecutionContext,r.removesuffix('()')) for r in refs})
(root/'conf.py').write_text("project='Execution context documentation check'\nmaster_doc='index'\n")
page='Execution context\n=================\n\n.. py:module:: tensorrt\n\n.. py:class:: IExecutionContext\n\n'
for method in ('execute_async_v3','execute_v2'):
    assert hasattr(trt.IExecutionContext,method)
    page+=f'   .. py:method:: {method}()\n\n      Runtime API exists in TensorRT {trt.__version__}.\n\n'
page+='   .. py:method:: set_device_memory(memory, size)\n\n'
page+='\n'.join('      '+line.strip() for line in doc.strip().splitlines())+'\n'
(root/'index.rst').write_text(page)

```
