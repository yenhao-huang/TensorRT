## 設計

在 runner 預設 host output 還原邏輯陣列，使用 runtime strides、vectorized dimension、components per element；排除 channel padding。必須在 D2H stream synchronize 後才能讀取資料。明確要求 raw buffers 或 device buffers 時保持 FormattedArray。

依據 TensorRT `getTensorStrides` 文件（include/NvInferRuntime.h）：stride 單位為 vector，HWC8 一單位含8個 scalar。

## 問題釐清與解決方法

`TrtRunner` 對 vectorized output 只回傳 `FormattedArray(raw_bytes, shape)`；它沒有 dtype／strides 資訊，直接把 `.array` 傳給 comparator 會錯把 FP16 位元組當 UINT8，並把 padding 算進統計。修正在 runner 尚持有 engine/context metadata 的位置解包，而不是替 comparator 加上錯誤的 raw-byte 統計。

`_unpack_vectorized_output` 依 runtime shape／stride 與 vector width 建立 bounded strided view；將 vector 內的 scalar 維度移到 channel 維度後合併，裁除 padding，回傳 contiguous NumPy／PyTorch array。使用 byte-size 檢查防止越界，支援 empty shape。D2H 完成後才讀取 buffer，避免非同步 copy 競爭。

預設 CPU output 因此可直接列印、比對、驗證與儲存。`return_raw_buffers=True` 與預設 device vectorized output 保持 `FormattedArray`，方便原始 buffer 使用者。這項變更是 output 處理；不新增任意 vectorized input 自動編碼 API。

## 解決後 Demo

以下生成本次重現使用的 HWC8 engine，且對完整 arange output 做精確驗證。模型純程式生成，不需要外部權重。儲存為 `/data/tenserrt/investigations/4685/reproduce.py`：

```python
import numpy as np
import tensorrt as trt
from polygraphy.backend.trt import TrtRunner
from polygraphy.comparator import Comparator, RunResults
logger=trt.Logger(trt.Logger.ERROR)
builder=trt.Builder(logger)
network=builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.STRONGLY_TYPED))
x=network.add_input('x', trt.float16, (1,3,2,5))
y=network.add_identity(x).get_output(0)
y.name='y'
network.mark_output(y)
y.allowed_formats=1 << int(trt.TensorFormat.HWC8)
plan=builder.build_serialized_network(network,builder.create_builder_config())
assert plan is not None
open('/data/tenserrt/investigations/4685/hwc8.engine','wb').write(plan)
engine=trt.Runtime(logger).deserialize_cuda_engine(plan)
with TrtRunner(engine) as runner:
    print('format',engine.get_tensor_format('y'),'strides',runner.context.get_tensor_strides('y'))
    inputs=np.arange(30,dtype=np.float16).reshape(1,3,2,5)
    outputs=runner.infer({'x':inputs})
    print('output type',type(outputs['y']))
    results=RunResults()
    results.add([outputs],runner_name='hwc8')
    assert Comparator.validate(results,check_inf=True,check_nan=True)
    np.testing.assert_array_equal(outputs['y'],inputs)

```
